# Megogo Content & Viewing Data Analysis (SQL)

## Overview
SQL analysis of video content and user viewing behavior using Google BigQuery.
The project focuses on data filtering, aggregation, and user segmentation
for product and marketing use cases.

## Tools
- Google BigQuery
- SQL (DDL, WHERE, GROUP BY, HAVING, CASE)

## Key Tasks
- Created a personal working schema and replicated source tables.
- Filtered and explored video content by type, rating, and age restrictions.
- Identified top-rated movies based on IMDB score.
- Analyzed content distribution using aggregation metrics.
- Calculated platform-level viewing metrics (users, sessions, watch time).
- Segmented loyal users for a marketing promotion campaign.

## Key Analyses
- Content type distribution and quality metrics.
- Platform usage patterns excluding TV content.
- Identification of high-value users based on viewing behavior.

## Business Use Case
- Support content strategy decisions.
- Prepare user segments for targeted promo campaigns.
- Evaluate platform engagement across devices.
