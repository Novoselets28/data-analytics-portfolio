# Google Sheets: Uber Trips Data Analysis

## Overview
- Cleaned and prepared raw Uber trip data for analysis.
- Enriched dataset with calculated fields (trip duration, time of day, categories, purposes).
- Identified and handled anomalous values using validation and conditional formatting.
- Analyzed trips by category and purpose using formulas and pivot tables.
- Explored seasonal and time-based trends (monthly, weekday, daypart).
- Built visualizations (line charts, bar charts) to support insights.
- Summarized findings and business insights.

## Key Insights
- Business trips dominate morning and daytime hours.
- Personal trips are more frequent in the evening.
- Average trip duration is higher on weekends.
